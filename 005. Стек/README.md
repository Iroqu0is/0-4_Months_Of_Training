### 6. `06-ThreadSafe-Stack-Cancellation` — Потокобезопасный стек с контролем асинхронной отмены (4 месяца обучения)
* **Какую задачу решал:** Проектировал структуру данных LIFO (Стек) повышенной надежности, способную безопасно работать в многопоточной среде и корректно прерывать длительные операции выделения памяти при получении системного сигнала отмены.
* **Ключевые фичи:**
  * **Синхронизация через критические секции:** Все мутирующие методы (`Push`, `Pop`, `Reset`) защищены блокировками `lock (stub)`, предотвращающими состояние гонки (Race Condition).
  * **Интеграция Cancellation Token:** Внедрен кастомный механизм `CancellationControl`, который периодически опрашивает токен отмены, защищая приложение от зависания при обработке сверхбольших массивов данных (10+ млн элементов).
  * **Управление ресурсами CPU:** Создан конфигуратор `CancellationDirection`, автоматически рассчитывающий оптимальный уровень параллелизма (`MaxDegreeOfParallelism`) на основе доступных ядер процессора.
