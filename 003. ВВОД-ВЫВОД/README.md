### 3. `03-File-IO-Streams` — Работа с файловой системой и потоками данных (3 месяца обучения)
* **Какую задачу решал:** Глубоко разбирался с системным вводом-выводом (I/O), концепцией стримов (Streams) и декораторов потоков по продвинутым материалам Джозефа и Бена Албахари.
* **Что интересного внутри:**
  * **Конвейеры потоков (Stream Pipelining):** Реализована сквозная запись через цепочку потоков `FileStream -> DeflateStream -> StreamWriter`.
  * **Безопасное управление ресурсами (Паттерн `using`):** В процессе рефакторинга (после подсказки AI-ассистента о важности предотвращения утечек дескрипторов) код был переведен со старого ручного закрытия потоков на современные блоки `using` для гарантированной очистки буферов и памяти.
  * **Защитная логика файловой системы:** Метод записи автоматически проверяет существование целевой директории и принудительно создает её (`Directory.CreateDirectory`), предотвращая падение программы.
  * **Диагностика производительности:** Интегрирован класс `Stopwatch` для точного замера времени выполнения дисковых операций в миллисекундах.
