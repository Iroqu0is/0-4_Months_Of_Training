### 5. `05-Custom-LINQ-Generic-Math` — Создание собственного аналога LINQ и Generic Math (3.7 месяца)
* **Задача:** Изучение внутреннего устройства методов расширения LINQ, механизмов ленивых вычислений (`yield`) и современных возможностей обобщенной математики (.NET Generic Math).
* **Ключевые фичи:**
  * **Использование `INumber<T>`:** Реализована строгая обобщенная математика для любых числовых типов данных с использованием системных констант вроде `T.Zero`.
  * **Собственные механизмы итерации:** Методы `MySelect` и `Where` спроектированы на основе конечных автоматов (`yield return`), обеспечивая потоковую обработку данных без лишних аллокаций памяти.
  * **Безопасность вычислений:** Внедрен контекст `checked` для защиты агрегирующего метода `MySum` от скрытого переполнения разрядной сетки типов.
  * **Оптимизация предикатов:** Методы `CheckAll` и `CheckAny` содержат логику раннего выхода из цикла (`break`), минимизируя нагрузку на процессор.
