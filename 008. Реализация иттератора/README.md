### 3. `03-Custom-Enumerable-Iterator` — Полная реализация итераторов по Шилдту (3 месяца)
* **Задача:** Изучение механизмов работы цикла `foreach`, проектирование кастомных индексаторов и освоение контрактов `IEnumerable` / `IEnumerable<T>`.
* **Ключевые фичи:**
  * **Двойная реализация контрактов:** Написана корректная интеграция старого необобщенного и современного generic-итераторов по стандартам платформы .NET.
  * **Именованные генераторы (`yield return`):** Реализован кастомный метод `GetData()`, поставляющий данные «на лету» в виде ленивой последовательности.
  * **Конвейерная обработка:** В методе `Main` продемонстрирована успешная стыковка кастомного итератора со стандартными предикатами LINQ.
