## 📁 Проект: Геометрическая координатная система и ООП (2 месяца обучения)

* **Папка в репозитории:** `02-Geometry-Coordinate-System`
* **Какую задачу решал:** Закреплял основы объектно-ориентированного программирования на примере работы с точками в двумерном пространстве Декарта. Учился автоматизировать расчеты и безопасно управлять состоянием объекта.

### Что интересного реализовано в коде:
1. **Автоматическое определение четверти:** С помощью перечисления (`enum Quarter`) класс при создании точки сам вычисляет, в какой координатной четверти она находится, включая пограничные случаи (лежит на осях X/Y или находится в начале координат).
2. **Мягкая обработка Null:** Все математические методы и перегруженные операторы содержат защитную логику. Если в метод передать `null`, программа не упадет, а подставит дефолтную точку `(0,0)`.
3. **Фабричные методы (Factory Method):** Вместо прямого вызова `new` реализованы статические методы `Point.Create()`, что является классическим паттерном проектирования.
4. **Многоуровневое логирование (`StringBuilder`):** Метод `GetFullInformation` собирает детальную сводку об объекте (включая расстояние до начала координат с точностью до двух знаков `:f2`) без лишнего выделения памяти на пересоздание строк.
5. **Кастомное исключение:** В проекте заложена основа для собственной обработки ошибок через создание класса `MyException : Exception`.
