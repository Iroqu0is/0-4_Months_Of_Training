## 🛠 Что внутри (Разбор по файлам)


### 1. Потокобезопасная коллекция `Salvatory<T>` и стек `Pile<T>`
Мои варианты структур данных на базе обычных динамических массивов.
* **Работа с потоками:** Использовал `ReaderWriterLockSlim`, чтобы чтение данных не блокировало другие читающие потоки.
* **Токены отмены:** В циклы поиска добавил проверку `CancellationToken` (с шагом раз в 10 000 итераций), чтобы можно было прервать долгую операцию.
* **Освобождение ресурсов:** Реализовал интерфейс `IDisposable` для корректного закрытия системных локов.

### 2. Классы данных: `Person` и `Employee`
Тренировался работать с наследованием, полиморфизмом и базовыми контрактами .NET.
* Перегрузил операторы сравнения (`==`, `!=`, `<`, `>`, `<=`, `>=`).
* Реализовал стандартные интерфейсы `IComparable`, `IEquatable` и `ICloneable`.
* Написал хэширование через `HashCode.Combine` с приведением строк к одному регистру, чтобы избежать колизий.
* Добавил `[JsonConstructor]` для корректной работы с сериализацией.

### 3. Рефлексия и валидация (`Extensions.cs` и `InRange`)
Попытка написать свой механизм проверки данных на лету.
* Создал кастомный атрибут `[InRange]` для задания границ (например, для возраста).
* Через **Reflection (Рефлексию)** написал метод `.InRange()`, который сканирует поля и свойства объекта и проверяет, укладываются ли они в рамки атрибута.
* Переписал метод валидации строк, чтобы он нормально пропускал имена с апострофами (например, *Д`Артаньян*).

### 4. Журнал ошибок `SimpleLogger`
Потокобезопасный логгер на базе `StringBuilder` и локов `ReaderWriterLockSlim`. Собирает записи из разных потоков, умеет выдавать строку отчета и сразу очищать буфер через `Report(clear: true)`.

### 5. Свой аналог `.Where()` из LINQ (`ForLINQ.cs`)
Разобрался, как устроены ленивые вычисления под капотом. Разделил метод на публичную проверку аргументов на `null` (срабатывает сразу) и приватный итератор с `yield return` (срабатывает только при переборе элементов). Это защищает от ситуации, когда ошибка из-за пустого аргумента вылезает «неизвестно где».

### 6. Асинхронный запуск (`Program.cs`)
Собрал все куски кода вместе в асинхронном методе `Main`:
* `CancellationControl` настраивает лимиты параллелизма (`MaxDegreeOfParallelism`) в зависимости от ядер процессора.
* Файлы пишутся и читаются с диска асинхронно через `Task.WhenAll`.
* Данные гоняются в JSON, а возникающие сбои пишутся в `SimpleLogger`.
